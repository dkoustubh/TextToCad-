# Communication Architecture

The Autodesk Agent should establish an authenticated outbound connection to the central AI server.

Prefer:

```text
Autodesk Agent
        ↓
WebSocket / secure persistent connection
        ↓
192.168.11.86
```

The server should NOT blindly expose privileged Autodesk APIs to the LAN.

The agent should:

1. Register itself.
2. Identify the machine.
3. Identify available Autodesk applications.
4. Report its current status.
5. Send heartbeat messages.
6. Receive approved jobs.
7. Execute one Autodesk operation at a time.
8. Return structured results.
9. Report errors.
10. Disconnect safely if the Autodesk application crashes.

For the prototype, the connection can use HTTP/WebSocket on the trusted LAN, but design the interfaces so HTTPS/WSS and proper authentication can be added.

# Natural Language → Structured Intent

Do NOT let Gemma directly generate arbitrary code.

For:

> Create a cube of 3 cm.

Gemma should produce a structured tool call similar to:

```json
{
  "tool": "inventor.create_box",
  "parameters": {
    "length_mm": 30,
    "width_mm": 30,
    "height_mm": 30
  }
}
```

The backend must validate this structured request before sending it to the Autodesk Agent.

The validation layer must verify:

* tool exists
* parameters exist
* parameters have correct types
* dimensions are valid
* units are normalized
* user is authorized
* Autodesk workstation is connected
* Autodesk application is available
* workstation is not already executing another conflicting operation

Never trust raw LLM output.

# Reliability Requirements

This system will eventually be used by many engineers simultaneously.

Therefore:

1. Never store active jobs only in Python memory.
2. Use Redis for job state.
3. Use PostgreSQL for persistent job history.
4. Give every job a unique ID.
5. Give every Autodesk workstation a unique agent ID.
6. Maintain per-workstation execution queues.
7. Allow only one conflicting CAD operation at a time per workstation.
8. Implement agent heartbeat.
9. Detect disconnected agents.
10. Retry only safe operations.
11. Never blindly retry destructive CAD operations.
12. Maintain audit logs.
13. Never expose Autodesk credentials to the LLM.
14. Never allow the LLM unrestricted shell access.
15. Never allow arbitrary Python execution from an LLM tool call.
